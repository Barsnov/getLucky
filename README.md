# «Лови Удачу!» (Мистерия) — Интерактивная 3D-викторина

Интерактивная командная игра-викторина с захватом гексагонального 3D-поля, разработанная в качестве дипломного проекта. Предназначена для проведения соревнований между командами по различным специальностям и проверке профильных знаний.

---

## 🎮 Игровой процесс

- **Команды:** от 2 до 5 команд (Красные, Синие, Зелёные, Жёлтые, Фиолетовые).
- **Поле:** 37 гексагональных клеток (3 кольца вокруг центрального гекса).
- **Механики:**
  1. **Захват нейтральной клетки:** игрок выбирает доступную клетку в радиусе хода и отвечает на карточку вопроса. При успехе клетка переходит команде, а фишка занимает новую позицию.
  2. **Свободное перемещение:** игрок может свободно перемещаться по клеткам, уже принадлежащим его команде, без траты хода.
  3. **Укрепление клетки (иммунитет):** двойной клик по клетке, на которой уже стоит фишка игрока, открывает карточку улучшения. При правильном ответе клетка получает статус `immune` и защитный световой луч, блокирующий вражеские атаки.
  4. **Дуэль за чужую клетку:** атака незащищённой чужой клетки запускает состязание один на один между атакующей и защищающейся командами («Словодел» или визуальная дуэль «Найди меня!»).
  5. **Подсчёт очков:** базовые очки команд умножаются на территориальный коэффициент (`multiplier = normal * 3 + immune * 10`), итоговый счёт: `baseScore * (1 + multiplier * 0.02)`.
  6. **Админ-панель:** защищённая кодом безопасности панель управления специальностями и пулами вопросов всех категорий.

## 🛠 Технологический стек

- **Backend:** [Laravel 12](https://laravel.com/) (PHP 8.2+), [Inertia.js 2](https://inertiajs.com/), Eloquent ORM, SQLite / MariaDB (Docker Sail), морфологическая библиотека `phpMorphy`.
- **Frontend Core:** [Vue 3](https://vuejs.org/) (`<script setup lang="ts">`), [TypeScript](https://www.typescriptlang.org/), [Pinia 4](https://pinia.vuejs.org/), [Tailwind CSS](https://tailwindcss.com/) + `@tailwindcss/typography`.
- **3D & Графика:** Чистый [Three.js](https://threejs.org/) (отказ от декларативного VDOM TresJS):
  - Модульный движок рендеринга (`SceneManager`, `BoardView`, `UnitManager`, `CameraController`, `InteractionManager`).
  - Постпроцессинг `EffectComposer` + `UnrealBloomPass`.
  - Рейкастинг кликов и наведений через `THREE.Raycaster`.
- **Звук и UI:** [Howler.js](https://howlerjs.com/) (через `useAudioStore`), [Swiper 11](https://swiperjs.com/), `markdown-it` + `markdown-it-mark` (через composable `useMarkdown`).

## 🏗 Архитектура приложения

Приложение построено по принципу строгого разделения ответственности на 4 слоя:

```
resources/js/
├── Types/                  # Строгая типизация (game.ts, cards.ts, admin.ts)
├── Game/
│   ├── Core/               # Чистые доменные классы без Three.js и Vue
│   │   ├── HexBoard.ts         # Генерация сетки (37 гексов), расстояния, радиус хода
│   │   ├── PlayerRegistry.ts   # Реестр команд, цветов, 3D-моделей и стартовых позиций
│   │   ├── QuestionDeck.ts     # Пулы карточек, взвешенный рандом
│   │   └── ScoreCalculator.ts  # Расчёт территориальных мультипликаторов и мест
│   └── Renderer/           # 3D-движок на чистом Three.js (вне реактивности Vue)
│       ├── SceneManager.ts       # Главный фасад сцены (подписка на Pinia store.$subscribe)
│       ├── BoardView.ts          # Отрисовка 37 гексов на общей геометрии, лучи иммунитета
│       ├── UnitManager.ts        # 3D-фишки игроков (GLTF) и корона с lerp-анимацией
│       ├── CameraController.ts   # Орбитальный облет и квадрантная фокусировка камеры
│       ├── InteractionManager.ts # Raycaster (hover, click, double click) -> Pinia Actions
│       ├── PostProcessingManager.ts # Bloom-эффект свечения
│       ├── AssetLoader.ts        # Кэширующий загрузчик GLTF-моделей
│       ├── WelcomeSceneManager.ts# Оптимизированный 3D-фон начального экрана (721 гекс)
│       └── PodiumSceneManager.ts # 3D-сцена награждения победителей на пьедестале
├── Stores/                 # Pinia сторы (Single Source of Truth)
│   ├── useGameStore.ts         # Состояние игры, конечный автомат GamePhase, экшены
│   └── useAudioStore.ts        # Централизованное управление звуками (SFX) и музыкой (BGM)
├── Composables/
│   └── useMarkdown.ts      # Парсинг Markdown с поддержкой подсветки ==выделение==
└── Pages/                  # Тонкие Vue HUD-компоненты (только интерфейс)
    ├── Game.vue            # Лейаут игры + HUD (очередь, таймер, рулетка)
    ├── GameComponents/     # GameCanvas.vue, Leaderboard.vue, Fight.vue, Questions.vue
    ├── Welcome.vue         # Стартовый экран + выбор параметров игры
    ├── Podium.vue          # Экран итогов и пьедестал
    └── Admin.vue           # Админ-панель
```

## 🚀 Пошаговый запуск проекта локально

### 1. Системные требования
- **PHP:** 8.2 или новее (с расширениями `pdo`, `pdo_sqlite`, `pdo_mysql`, `mbstring`, `xml`, `curl`).
- **Composer:** 2.x.
- **Node.js:** 18.x или 20.x LTS + **npm**.
- **База данных:** SQLite (по умолчанию для быстрой локальной работы) или MariaDB / MySQL.

---

### 2. Установка зависимостей

Перейдите в корень проекта и установите PHP- и Node-зависимости:

```bash
cd /path/to/Diplom

# Установка зависимостей бэкенда
composer install

# Установка зависимостей фронтенда
npm install
```

---

### 3. Настройка файла окружения (`.env`)

Скопируйте файл конфигурации:

```bash
cp .env.example .env
php artisan key:generate
```

#### Вариант А: Быстрый запуск на SQLite (по умолчанию)
В файле `.env` убедитесь, что указано:
```env
DB_CONNECTION=sqlite
```
Создайте файл базы данных (если не создан):
```bash
touch database/database.sqlite
```

#### Вариант Б: Использование MariaDB / MySQL (с готовым дампом `hex_db.sql`)
Если вы хотите использовать базу данных с уже заполненными специальностями и вопросами:
1. Создайте базу данных `hex_db` в MySQL/MariaDB:
   ```sql
   CREATE DATABASE hex_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```
2. Импортируйте готовый дамп:
   ```bash
   mysql -u root -p hex_db < hex_db.sql
   ```
3. В `.env` укажите параметры подключения:
   ```env
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=hex_db
   DB_USERNAME=ваш_пользователь
   DB_PASSWORD=ваш_пароль
   ```

---

### 4. Миграции и симлинк на хранилище

Если база пустая (без импорта дампа), примените миграции:
```bash
php artisan migrate
```

Обязательно создайте символическую ссылку на директорию хранения изображений карточек (категория «Найди меня!» и аватары):
```bash
php artisan storage:link
```

---

### 5. Запуск серверов разработки

Для полноценной работы проекта требуются сервер Laravel и сборщик Vite.

#### Вариант 1: Запуск одной командой через concurrently
В `composer.json` уже настроен удобный скрипт:
```bash
composer run dev
```
Он одновременно поднимет `php artisan serve` и `npm run dev`.

#### Вариант 2: Запуск в двух отдельных терминалах

**Терминал 1 (Vite Dev Server):**
```bash
npm run dev
```

**Терминал 2 (Laravel Backend):**
```bash
php artisan serve
```

По умолчанию приложение будет доступно по адресу: **http://localhost:8000** (или по порту, выведенному `php artisan serve`).

---

### 6. Запуск в локальной сети (для игры с нескольких устройств / планшета)

Если вы хотите подключиться к игре с другого устройства в той же Wi-Fi сети:
1. Узнайте локальный IP вашего компьютера (в Linux: `ip a` или `hostname -I`; в Windows: `ipconfig`). Например, `192.168.1.100`.
2. В файле `.env` укажите:
   ```env
   APP_URL=http://192.168.1.100:8000
   ```
3. Запустите бэкенд на всех интерфейсах:
   ```bash
   php artisan serve --host=0.0.0.0 --port=8000
   ```
4. Откройте в браузере второго устройства адрес `http://192.168.1.100:8000`.

---

## 🔐 Доступ в Админ-панель

1. Перейдите по адресу: `/auth` (или нажмите иконку профиля в интерфейсе).
2. Система запросит 5-значный секретный код безопасности.
3. Проверка кода выполняется контроллером `UserController@check` относительно хеша `admin_code` пользователя с ролью администратора (`role = 1`) в таблице `users`.
4. В админ-панели (`/admin`) доступно создание, редактирование и удаление специальностей и карточек всех 7 типов.
