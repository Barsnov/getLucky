Дипломная игрушка-викторина, созданная для разных специальностей по мере их заполнения. Для локальных решений используется sqlite база данных.
Используется визуальное представление с помощью Web3D технологий + обычного html DOM. На админ-панели стоит защита, где нужно ввести код-безопасности, там добаляются специальности и идёт наполнение её вопросами. Вопросы бывают разных типов. Также используется словарь для составления слов и огромного слова в категории "Cлово-Дел" 


Стек: Laravel(php), Vue(Option.api + Composition.api), tailwind.css, Inertia.js

Языки: js, html, css3

Библиотеки: swiper.js, howler.js, markdown-it, three.js, tresJS




Для того, чтобы запустить проект локально на каком-либо устройстве, нужно:
    1.Настроить в .env файле url устройства (где будет работать сервер).
        1.1. Чтобы проверить его просто в CMD "ipconfig" ввести и норм. 
        1.2. Потом поменять его на этой строчке: APP_URL=http://ваш ip:8003

    2. Далее в vite.config.js поменять также ip, где будет работать наш vite
        hmr: {
            host: 'ваш ip', // нужно, чтобы ip здесь и выше совпадали, на были на разных портах.
        }
    3. Далее в одной консоли прописываем "npm run dev"
    4. А в другой прописываем "php artisan serve --host=0.0.0.0 --port=8003". Порты должны совпадать, т.к. в .env указан 8003, но может быть и другой.

И.. всё должно заработать!
